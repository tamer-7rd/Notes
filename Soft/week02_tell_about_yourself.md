# «Расскажите о себе» — для Junior

## 🎯 Что хочет услышать интервьюер?

Когда спрашивают "Расскажите о себе", интервьюер хочет:
1. Понять, кто ты как специалист
2. Услышать релевантный опыт
3. Понять твою мотивацию
4. Оценить коммуникацию

**НЕ хочет услышать:** Где родился, сколько братьев/сестёр, хобби (если не спрашивают).

---

## 📝 Структура ответа (2-3 минуты)

### 1. Текущая ситуация (30 сек)
```
"Сейчас я Junior Fullstack Developer. Работаю с React на фронте 
и Node.js на бэке. Активно развиваюсь в веб-разработке."
```

### 2. Путь к IT (30-60 сек)
```
"В IT я пришёл [год назад / после курсов / из другой сферы]. 
Меня привлекло [что именно]. Начал с [языка/технологии], 
постепенно перешёл к fullstack-разработке."
```

### 3. Ключевые навыки и проекты (60 сек)
```
"За это время я создал несколько проектов. Например, [название] — 
это [описание]. В нём я использовал [технологии] и научился [навыки]."
```

### 4. Почему эта компания / позиция (30 сек)
```
"Сейчас я ищу позицию, где смогу [расти / применить навыки / 
работать над интересными задачами]. Ваша компания привлекла меня 
[чем именно — продукт, стек, команда]."
```

---

## 🎬 Полный пример ответа

```
"Сейчас я Junior Fullstack Developer. Работаю с React и TypeScript 
на фронте, Node.js и PostgreSQL на бэке.

В программирование я пришёл два года назад. Начал с Python, 
потом увлёкся веб-разработкой и JavaScript. Прошёл несколько 
курсов и много практиковался на pet-проектах.

Мой главный проект — SpeedTypingTest, веб-приложение для тренировки 
скорости печати. В нём я реализовал систему аутентификации, 
таблицу рекордов и real-time обновление результатов. Этот проект 
помог мне понять полный цикл разработки — от идеи до деплоя.

Ваша компания привлекла меня тем, что вы работаете с современным 
стеком и уделяете внимание качеству кода. Я хочу расти в команде, 
где смогу учиться у опытных разработчиков и приносить пользу."
```

## ❌ Частые ошибки

### 1. Слишком много личного
```
❌ "Родился в Москве, закончил школу №123, потом поступил в..."
✅ "Я Junior Developer, специализируюсь на React и Node.js..."
```

### 2. Перечисление всех технологий
```
❌ "Знаю HTML, CSS, JavaScript, React, Vue, Angular, Node, Python, 
    Java, C++, PostgreSQL, MongoDB, Redis, Docker, Kubernetes..."
✅ "Основной стек — React и Node.js. Также работал с PostgreSQL 
    и Docker для деплоя."
```

### 3. Негатив о прошлом
```
❌ "Ушёл с прошлой работы, потому что там был ужасный менеджмент..."
✅ "Решил сменить направление, чтобы развиваться в IT."
```

### 4. Извинения
```
❌ "Я всего лишь junior, многого не знаю..."
✅ "Я активно учусь и готов погружаться в новые задачи."
```

## 🎯 Адаптация под компанию

### Для стартапа:
```
"...Мне нравится работать в динамичной среде, где нужно быстро 
осваивать новые технологии и видеть результат своей работы."
```

### Для крупной компании:
```
"...Хочу работать над масштабными проектами, где можно учиться 
у опытных специалистов и следовать лучшим практикам."
```

### Для продуктовой компании:
```
"...Меня привлекает возможность работать над одним продуктом 
вглубь, понимать его архитектуру и видеть, как мои изменения 
влияют на пользователей."
```

## 📋 Чек-лист перед собеседованием

- [ ] Мой ответ занимает 2-3 минуты?
- [ ] Я рассказал о текущих навыках?
- [ ] Я упомянул конкретный проект?
- [ ] Я объяснил, почему эта компания?
- [ ] Я не ушёл в личную биографию?
- [ ] Я отрепетировал вслух?

---

## 🔄 Варианты вопроса

Эти вопросы требуют похожего ответа:
- "Расскажите о себе"
- "Расскажите о своём опыте"
- "Почему вы хотите работать разработчиком?"
- "Расскажите о своём пути в IT"

---

## 🎓 Главное:

1. **Структура:** Текущая ситуация → Путь → Проекты → Мотивация
2. **Время:** 2-3 минуты (не больше!)
3. **Фокус:** На релевантном опыте, не на личной биографии
4. **Конкретика:** Технологии, проекты, результаты
5. **Адаптация:** Подстрой финал под компанию

**Запомни:** "Расскажите о себе" — это возможность направить разговор в нужное русло. Подготовь ответ заранее!
