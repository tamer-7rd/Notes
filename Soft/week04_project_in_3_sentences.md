# Описать проект в 3 предложениях — для Junior

## 🎯 Зачем нужно короткое описание?

Иногда нужно описать проект очень кратко:
- В резюме / LinkedIn
- Когда времени мало
- Когда спрашивают "А что за проект?" между делом
- В сопроводительном письме

**Правило:** 3 предложения = 30 секунд = вся суть проекта.

---

## 📝 Формула 3 предложений

### Предложение 1: ЧТО это?
```
"[Название] — это [тип приложения] для [целевая аудитория]."
```

### Предложение 2: ЗАЧЕМ / Какую проблему решает?
```
"Позволяет [что делать] / Помогает [с чем]."
```

### Предложение 3: КАК / На чём сделано?
```
"Сделано на [технологии], задеплоено на [где]."
```

---

## 🎬 Примеры

### Пример 1: SpeedTypingTest
```
"SpeedTypingTest — это веб-приложение для тренировки скорости печати.
Позволяет отслеживать WPM и точность, сохранять рекорды.
Сделано на React + Node.js, задеплоено на Vercel."
```

### Пример 2: Todo App
```
"TaskMaster — это приложение для управления задачами с drag-and-drop.
Помогает организовать задачи по категориям и отслеживать прогресс.
React + TypeScript на фронте, Express + PostgreSQL на бэке."
```

### Пример 3: E-commerce
```
"ShopDemo — демо интернет-магазина с корзиной и оплатой.
Пользователи могут просматривать товары, фильтровать и оформлять заказы.
Next.js + Stripe API + Supabase для базы данных."
```

### Пример 4: Чат
```
"ChatApp — real-time чат с комнатами и уведомлениями.
Поддерживает приватные сообщения и групповые чаты.
React + Socket.io + MongoDB."
```

### Пример 5: API
```
"NewsAggregator API — бэкенд для агрегации новостей из разных источников.
Автоматически парсит и категоризирует статьи.
Node.js + PostgreSQL + scheduled jobs для парсинга."
```

## 🔄 Вариации для разных контекстов

### Для резюме (максимально кратко):
```
"SpeedTypingTest: React + Node.js. Тренировка печати с таблицей рекордов."
```

### Для LinkedIn:
```
"🚀 SpeedTypingTest — веб-приложение для тренировки скорости печати.
Tech stack: React, TypeScript, Node.js, PostgreSQL.
Live demo: [ссылка]"
```

### Для сопроводительного письма:
```
"В своём проекте SpeedTypingTest я реализовал полный цикл разработки: 
от дизайна до деплоя. Использовал React для фронтенда и Node.js 
для бэкенда, что позволило мне понять fullstack-разработку изнутри."
```

## ❌ Плохие примеры

### Слишком абстрактно:
```
❌ "Это веб-приложение. Использует современные технологии. Работает хорошо."
✅ "SpeedTypingTest — тренажёр печати. Показывает WPM и точность. React + Node.js."
```

### Слишком много деталей:
```
❌ "Это приложение, которое я начал делать в августе, использует React 18.2 
    с хуками useState и useEffect, бэкенд на Express с middleware для CORS..."
✅ "Тренажёр печати на React + Node.js с таблицей рекордов."
```

### Нет сути:
```
❌ "Мой первый проект. Было интересно делать. Научился многому."
✅ "Тренажёр печати: измеряет скорость, сохраняет рекорды, React + Node.js."
```

## 📋 Шаблоны для быстрого заполнения

### Шаблон 1 (Универсальный):
```
"[Название] — [тип] для [аудитория/цель].
[Главная функция / что делает].
[Технологии]."
```

### Шаблон 2 (Проблема-решение):
```
"[Название] решает проблему [какую].
[Как решает].
Стек: [технологии]."
```

### Шаблон 3 (Для учебного проекта):
```
"[Название] — учебный проект для освоения [чего].
[Что реализовал].
[Технологии]."
```

## 🎓 Главное:

1. **3 предложения** = ЧТО + ЗАЧЕМ + КАК
2. **Конкретика:** Называй технологии, не говори "современный стек"
3. **Проблема:** Объясни, зачем это нужно
4. **Краткость:** 30 секунд максимум
5. **Адаптация:** Разные версии для резюме, LinkedIn, письма

**Запомни:** Если не можешь описать проект в 3 предложениях — ты не до конца понимаешь, что сделал!
