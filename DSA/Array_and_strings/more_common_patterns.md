# Другие распространённые паттерны

В этой статье мы кратко рассмотрим ещё несколько паттернов и распространённых приёмов, которые можно использовать в алгоритмических задачах на массивы и строки.

## Построение строки за O(n)

Ранее мы упоминали, что в большинстве языков строки являются неизменяемыми (immutable). Это означает, что добавление одного символа к строке — это операция за $O(n)$. Если у вас есть строка длиной 1 миллион символов, и вы хотите добавить ещё один символ, все 1 миллион символов нужно скопировать в другую строку.

Многие задачи требуют вернуть строку, и обычно эта строка строится в процессе работы алгоритма. Допустим, итоговая строка имеет длину `n`, и мы собираем её посимвольно с помощью конкатенации. Какова будет временная сложность? Количество операций на каждом шаге составит `1 + 2 + 3 + ... + n`. Это частичная сумма [этого ряда](https://en.wikipedia.org/wiki/1_%2B_2_%2B_3_%2B_4_%2B_%E2%8B%AF), что приводит к $O(n^2)$ операциям.

Простая конкатенация приведёт к временной сложности $O(n^2)$, если вы используете язык, где строки неизменяемы.

Существуют гораздо более эффективные способы построения строк — всего за $O(n)$ времени. Реализация зависит от языка программирования: ниже приведены примеры для Python, JavaScript и Java (для других языков рекомендуется изучить идиоматичные подходы к конструированию строк).

### Python

1. Объявите пустой список: `arr = []`.
2. Добавляйте символы через `.append()`. Это $O(1)$ за операцию, за `n` операций — $O(n)$ в сумме.
3. В конце соберите строку: `"".join(arr)`. Это $O(n)$.
4. Итого: $O(n + n) = O(2n) = O(n)$.

```python
def build_string(s):
    arr = []
    for c in s:
        arr.append(c)
    return "".join(arr)
```

### JavaScript

Та же идея: массив + `.join("")`.

```javascript
let buildString = s => {
    let arr = [];
    for (let i = 0; i < s.length; i++) {
        arr.push(s[i]);
    }
    return arr.join("");
};
```

### Java

1. Используйте класс **StringBuilder**.
2. При построении строки добавляйте символы в `StringBuilder`. Это $O(1)$ за операцию. За `n` операций это будет стоить $O(n)$ в сумме.
3. По завершении преобразуйте его в строку с помощью `StringBuilder.toString()`. Это $O(n)$.
4. Итого это стоит нам $O(n + n) = O(2n) = O(n)$.

```java
public String buildString(String s) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        sb.append(s.charAt(i));
    }

    return sb.toString();
}
```

> В C++ достаточно просто использовать `+=` при построении строк, поскольку строки являются изменяемыми (mutable).

## Подмассивы/подстроки, подпоследовательности и подмножества

Давайте быстро разберём разницу между этими понятиями и на что обращать внимание при встрече с ними в задачах.

### Подмассивы/подстроки (Subarrays/substrings)

> **Напоминание:** подмассив или подстрока — это **непрерывная (contiguous)** часть массива или строки.

Если в задаче есть явные ограничения, такие как:
- Сумма больше или меньше `k`
- Ограничения на содержимое, например, максимум `k` уникальных элементов или отсутствие дубликатов

И/или требуется найти:
- Минимальную или максимальную длину
- Количество подмассивов/подстрок
- Максимальную или минимальную сумму

**Подумайте о скользящем окне (sliding window).** Обратите внимание, что не все задачи с такими характеристиками решаются скользящим окном, и не все задачи на скользящее окно имеют эти характеристики. Эти характеристики следует использовать только как общее руководство.

Если входные данные задачи — массив целых чисел, и вам нужно вычислить суммы нескольких подмассивов, рассмотрите построение **префиксной суммы (prefix sum)**.

> [!NOTE]
> **Свойства формулы `j - i + 1`:**
> Формула `j - i + 1` для индексов `i` и `j` (включительно) означает сразу две вещи:
> 1. **Размер (длину)** текущего подмассива между `i` и `j`.
> 2. **Количество всех допустимых подмассивов**, которые заканчиваются в точке `j` и начинаются в `i` или позже. Это свойство постоянно используется в задачах на скользящее окно с подсчётом («найти число подмассивов, удовлетворяющих условию»).

### Подпоследовательности (Subsequences)

> **Подпоследовательность** — это набор элементов массива/строки, которые **сохраняют исходный относительный порядок**, но **не обязаны быть непрерывными**.
>
> Например, для `[1, 2, 3, 4]` подпоследовательностями являются: `[1, 3]`, `[4]`, `[]`, `[2, 3]`.  
> Но **не** являются: `[3, 2]` (нарушен порядок), `[5]` (нет такого элемента), `[4, 1]` (нарушен порядок).

#### Пример со скриншота курса:
```
Исходный массив:  [ 4,  2,  7,  6,  5,  1,  8 ]
                     \       \       \
Подпоследовательность: [ 4,      7,      5 ]
```
Элементы `2` и `6` пропущены, но относительный порядок элементов `4` $\to$ `7` $\to$ `5` сохранён.

Как правило, задачи на подпоследовательности сложнее. Поскольку это только первая глава, сейчас трудно говорить о паттернах для подпоследовательностей. Подпоследовательности появятся снова позже в курсе — например, **динамическое программирование (DP)** широко используется для решения множества задач на подпоследовательности.

Из паттернов, которые мы изучили до сих пор, наиболее распространённый, связанный с подпоследовательностями — это **два указателя (two pointers)**, когда даны два входных массива/строки (например, проверка, является ли одна строка подпоследовательностью другой). Поскольку префиксные суммы и скользящие окна опираются на непрерывность элементов, для общих подпоследовательностей они неприменимы.

### Подмножества (Subsets)

> **Подмножество** — это **любой набор элементов** из исходного массива или строки. Порядок **не имеет значения**, и элементы не обязаны идти подряд.
>
> Например, для `[1, 2, 3, 4]` все эти наборы являются подмножествами: `[3, 2]`, `[4, 1, 2]`, `[1]`.  
> *Примечание:* подмножества, содержащие одинаковые элементы, считаются эквивалентными, то есть `[1, 2, 4]` — это то же самое подмножество, что и `[4, 1, 2]`.

#### В чём разница между подпоследовательностями и подмножествами?
В подпоследовательностях порядок критичен:
- Допустим, вам нужно найти 3 последовательных числа (например, `1, 2, 3`).
- Для массива `[3, 2, 1]`:
  - **Подмножество** `{1, 2, 3}` здесь **есть** (все три числа присутствуют).
  - **Подпоследовательности** `[1, 2, 3]` здесь **нет** (числа расположены в обратном порядке).

Мы подробно рассмотрим генерацию подмножеств в главе о **бэктрекинге (backtracking)**.

> [!TIP]
> **Трюк с сортировкой:**  
> Если в задаче говорится о подпоследовательностях, но сам порядок элементов фактически не имеет значения (например, требуется найти *сумму* элементов подпоследовательности или просто проверить наличие элементов), вы можете рассматривать задачу как задачу на **подмножества**.  
> Главное преимущество подмножеств перед подпоследовательностями — входной массив можно **смело отсортировать (`nums.sort()`)**, что открывает дорогу к бинарному поиску, двум указателям и жадным алгоритмам! В задачах на подпоследовательности сортировка разрушила бы исходный порядок.
