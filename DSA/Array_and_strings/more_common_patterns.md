# Другие распространённые паттерны

В этой статье мы кратко рассмотрим ещё несколько паттернов и распространённых приёмов, которые можно использовать в алгоритмических задачах на массивы и строки.

## Построение строки за O(n)

Ранее мы упоминали, что в большинстве языков строки являются неизменяемыми (immutable). Это означает, что добавление одного символа к строке — это операция за $O(n)$. Если у вас есть строка длиной 1 миллион символов, и вы хотите добавить ещё один символ, все 1 миллион символов нужно скопировать в другую строку.

Многие задачи требуют вернуть строку, и обычно эта строка строится в процессе работы алгоритма. Допустим, итоговая строка имеет длину `n`, и мы собираем её посимвольно с помощью конкатенации. Какова будет временная сложность? Количество операций на каждом шаге составит `1 + 2 + 3 + ... + n`. Это частичная сумма [этого ряда](https://en.wikipedia.org/wiki/1_%2B_2_%2B_3_%2B_4_%2B_%E2%8B%AF), что приводит к $O(n^2)$ операциям.

Простая конкатенация приведёт к временной сложности $O(n^2)$, если вы используете язык, где строки неизменяемы.

Существуют более эффективные способы построения строк всего за $O(n)$. Это зависит от языка — здесь мы рассмотрим Python и Java. Если вы используете другой язык, рекомендуем изучить лучший способ построения строк в вашем языке.

### Python

1. Объявите список
2. При построении строки добавляйте символы в список. Это $O(1)$ за операцию. За `n` операций это будет стоить $O(n)$ в сумме.
3. По завершении преобразуйте список в строку с помощью `"".join(list)`. Это $O(n)$.
4. Итого это стоит нам $O(n + n) = O(2n) = O(n)$.

```python
def build_string(s):
    arr = []
    for c in s:
        arr.append(c)

    return "".join(arr)
```

### JavaScript

Тот же процесс, что и в Python, с использованием метода `arr.join()`.

```javascript
let buildString = s => {
    let arr = [];
    for (let i = 0; i < s.length; i++) {
        arr.push(s[i]);
    }

    return arr.join("");
};
```

### Java

1. Используйте класс **StringBuilder**.
2. При построении строки добавляйте символы в список. Это $O(1)$ за операцию. За `n` операций это будет стоить $O(n)$ в сумме.
3. По завершении преобразуйте список в строку с помощью `StringBuilder.toString()`. Это $O(n)$.
4. Итого это стоит нам $O(n + n) = O(2n) = O(n)$.

```java
public string buildString(String s) {
    StringBuilder sb = new StringBuilder();
    for (int i = 0; i < s.length(); i++) {
        sb.append(s.charAt(i));
    }

    return sb.toString();
}
```

> В C++ достаточно просто использовать `+=` при построении строк, поскольку строки являются изменяемыми (mutable).

## Подмассивы/подстроки, подпоследовательности и подмножества

Давайте быстро разберём разницу между этими понятиями и на что обращать внимание при встрече с ними в задачах.

### Подмассивы/подстроки (Subarrays/substrings)

> Напоминание: подмассив или подстрока — это непрерывная (contiguous) часть массива или строки.

Если в задаче есть явные ограничения, такие как:

- Сумма больше или меньше `k`
- Ограничения на содержимое, например, максимум `k` уникальных элементов или отсутствие дубликатов

И/или требуется найти:

- Минимальную или максимальную длину
- Количество подмассивов/подстрок
- Максимальную или минимальную сумму

Подумайте о скользящем окне (sliding window). Обратите внимание, что не все задачи с такими характеристиками решаются скользящим окном, и не все задачи на скользящее окно имеют эти характеристики. Эти характеристики следует использовать только как общее руководство.

Если входные данные задачи — массив целых чисел, и вам нужно вычислить суммы нескольких подмассивов, рассмотрите построение префиксной суммы (prefix sum).

Размер подмассива между `i` и `j` (включительно) равен `j - i + 1`. Это также количество подмассивов, заканчивающихся на `j`, начиная с `i` или позже.

### Подпоследовательности (Subsequences)

> Подпоследовательность — это набор элементов массива/строки, которые сохраняют тот же относительный порядок, но не обязаны быть непрерывными.
>
> Например, подпоследовательности `[1, 2, 3, 4]` включают: `[1, 3]`, `[4]`, `[]`, `[2, 3]`, но не `[3, 2]`, `[5]`, `[4, 1]`.

Как правило, задачи на подпоследовательности сложнее. Поскольку это только первая глава, сейчас трудно говорить о паттернах для подпоследовательностей. Подпоследовательности появятся снова позже в курсе — например, динамическое программирование используется для решения множества задач на подпоследовательности.

Из паттернов, которые мы изучили до сих пор, наиболее распространённый, связанный с подпоследовательностями — это два указателя (two pointers), когда даны два входных массива/строки (мы рассматривали одну такую задачу в статьях о двух указателях). Поскольку префиксные суммы и скользящие окна работают с подмассивами/подстроками, они здесь неприменимы.

### Подмножества (Subsets)

> Подмножество — это любой набор элементов из исходного массива или строки. Порядок не имеет значения, и элементы не обязаны быть рядом друг с другом. Например, для `[1, 2, 3, 4]` все эти наборы являются подмножествами: `[3, 2]`, `[4, 1, 2]`, `[1]`. Примечание: подмножества, содержащие одинаковые элементы, обычно считаются одинаковыми, поэтому `[1, 2, 4]` — это то же подмножество, что и `[4, 1, 2]`.

Вы можете задаться вопросом: в чём разница между подпоследовательностями и подмножествами, если подмножества с одинаковыми элементами считаются одинаковыми? В подпоследовательностях порядок имеет значение — допустим, у вас есть массив целых чисел, и вам нужно найти подпоследовательность из 3 последовательных чисел (например, `1, 2, 3`). Это сложнее, чем найти *подмножество* из 3 последовательных чисел, потому что для подмножества эти 3 элемента просто должны существовать. В подпоследовательности элементы должны существовать в правильном относительном порядке. Например, массив `[3, 2, 1]` не имеет подпоследовательности, удовлетворяющей этому критерию, но имеет подмножество, которое удовлетворяет.

Опять же, поскольку мы только в первой главе, трудно много говорить о подмножествах. Мы увидим использование подмножеств в главе о бэктрекинге (backtracking).

Стоит отметить: если задача связана с подпоследовательностями, но порядок подпоследовательности на самом деле не важен (например, нужна сумма подпоследовательностей), то её можно рассматривать как задачу на подмножества. Полезная вещь, которую можно сделать с подмножествами, но нельзя с подпоследовательностями — это отсортировать входные данные, поскольку порядок не имеет значения.
