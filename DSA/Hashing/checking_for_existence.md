# Checking for existence

Одно из самых распространённых применений хеш-карты или множества — определение того, существует ли элемент, за O(1). Поскольку массиву для этого требуется O(n), использование хеш-карты или множества может значительно улучшить временную сложность алгоритма, обычно с O(n²) до O(n). (Массив ищет один элемент за O(n). Hash map ищет один элемент за O(1). Поэтому когда в алгоритме много таких поисков, общая сложность может улучшиться с O(n²) до O(n).) Давайте рассмотрим несколько примеров задач.

> Пример 1: 1. Two Sum
>
> Дан массив целых чисел `nums` и целое число `target`, верните индексы двух чисел, сумма которых равна `target`. Нельзя использовать один и тот же индекс дважды.

Давайте быстро подумаем, как мы могли бы решить эту задачу методом грубой силы (brute force). Мы могли бы просто проверить каждую пару чисел и посмотреть, дают ли они в сумме `target`. Используем один цикл for для итерации по массиву, и на каждой итерации фиксируем число `num`. Затем используем внутренний цикл for, который ищет `target - num` в массиве (потому что `num + target - num = target`).

Этот алгоритм медленный, потому что внутренний цикл (цель которого — найти `target - num`) стоит O(n). Таким образом, временная сложность составит O(n²). С хеш-картой мы можем искать `target - num` за O(1), что значительно улучшит временную сложность до O(n).

Мы можем строить хеш-карту по мере итерации по массиву, отображая каждое значение на его индекс. На каждом индексе `i`, где `num = nums[i]`, мы можем проверить нашу хеш-карту на наличие `target - num`. Добавление пар ключ-значение и проверка наличия `target - num` — всё это O(1), поэтому наша временная сложность улучшится до O(n).


```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        dic = {}
        for i in range(len(nums)):
            num = nums[i]
            complement = target - num
            if complement in dic: # This operation is O(1)!
                return [i, dic[complement]]

            dic[num] = i

        return [-1, -1]
```

> Если бы в задаче нужно было вернуть булево значение, указывающее, существует ли пара, или вернуть сами числа, тогда мы могли бы просто использовать множество (set). Однако, поскольку задача требует индексы чисел, нам нужно использовать хеш-карту, чтобы «запомнить», на каких индексах находятся числа.

Временная сложность составляет O(n), так как операции хеш-карты выполняются за O(1). Это решение также использует O(n) памяти, так как количество ключей, которые хеш-карта будет хранить, линейно зависит от размера входных данных.

> Пример 2: 2351. First Letter to Appear Twice
>
> Дана строка `s`, верните первый символ, который встречается дважды. Гарантируется, что во входных данных будет дублирующийся символ.

Решение методом грубой силы — итерировать по строке, и для каждого символа `c` снова итерировать до `c`, чтобы проверить, есть ли совпадение.

```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        for i in range(len(s)):
            c = s[i]
            for j in range(i):
                if s[j] == c:
                    return c
        return " "
```

Это O(n²) из-за вложенного цикла. Второй цикл проверяет существование `c`, что можно сделать за O(1) с помощью множества (set).

```python
class Solution:
    def repeatedCharacter(self, s: str) -> str:
        seen = set()
        for c in s:
            if c in seen:
                return c
            seen.add(c)
        return " "
```

Это улучшает нашу временную сложность до O(n), так как каждая итерация цикла for теперь выполняется за константное время.

Пространственная сложность — более интересная тема для обсуждения. Многие будут утверждать, что пространственная сложность составляет O(1), потому что входные данные могут содержать только символы английского алфавита, что ограничено константой (26). Это очень распространённо в задачах со строками и технически корректно. На собеседовании это, вероятно, безопасный ответ, но вам также стоит отметить, что пространственная сложность может быть O(m), где m — количество допустимых символов во входных данных. Это более общий ответ и тоже технически корректный.

> Пример 3: Дан массив целых чисел `nums`, найдите все числа `x` в `nums`, которые удовлетворяют следующему условию: `x + 1` отсутствует в `nums`, и `x - 1` отсутствует в `nums`.
>
> Если допустимое число `x` встречается несколько раз, его нужно включить в ответ только один раз.

Мы можем решить это простым способом — просто итерируем по nums и проверяем, есть ли `x + 1` или `x - 1` в `nums`. Преобразовав `nums` во множество заранее, эти проверки будут стоить O(1).

Преобразование входных данных во множество заранее — ещё один пример предварительной обработки (pre-processing).

```python
def find_numbers(nums):
    ans = []
    nums_set = set(nums)

    for num in nums_set:
        if (num + 1 not in nums_set) and (num - 1 not in nums_set):
            ans.append(num)

    return ans
```

Поскольку проверки выполняются за O(1), временная сложность составляет O(n), так как каждая итерация цикла for выполняется за константное время. Множество займёт O(n) памяти.
